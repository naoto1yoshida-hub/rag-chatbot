# RAGチャットボット 仕様書

## 概要
手元のPDFファイルをアップロードして、その内容について質問できるチャットボットです。複数のPDFファイルを一度に読み込ませ、その内容に基づいた回答を生成します。

## 主な機能
1. **複数PDFアップロード**: 
   - サイドバーから複数のPDFファイルを一度にアップロードできます。
2. **RAG（検索拡張生成）**: 
   - アップロードされたドキュメントの内容を検索し、回答を生成します。
3. **ソース引用とリンク機能** (New!): 
   - 回答の根拠となったPDFのファイル名とページ番号を回答の下に表示します。
   - 各ソース横の「開く」ボタンをクリックすると、PCのデフォルトPDFビューアで該当ファイルが開きます。
4. **チャット履歴**: 
   - 会話の文脈を保持しながらやり取りができます。
5. **履歴クリア**: 
   - 「クリア」ボタンで会話と読み込んだドキュメント情報をリセットできます。

## 仕様詳細

### 1. ファイル保存と管理
- **保存先**: アップロードされたPDFファイルは、プロジェクトフォルダ直下の `uploaded_docs` ディレクトリに保存されます。
- **永続化**: `.gemini/` などの一時フォルダではなく、ローカルフォルダに実ファイルとして保存されるため、OSの機能で直接開くことが可能です。
- **注意点**: プライバシー保護のため、不要になったファイルはユーザー自身で `uploaded_docs` フォルダから削除することを推奨します（アプリのリセットボタンでは元ファイルは削除されません）。

### 2. 回答生成プロセス
- **テキスト処理**: `LangChain` の `PyPDFLoader` でテキストを抽出後、`RecursiveCharacterTextSplitter` で分割（チャンク化）します。
- **ベクトル検索**: `OpenAIEmbeddings` でベクトル化し、`FAISS` ベクトルストアを用いて類似検索を行います。
- **回答生成**: 検索された関連テキスト（コンテキスト）をLLM（GPT-4o-mini）に渡し、回答を生成させます。

### 3. ソース引用機能
- **メタデータ抽出**: 検索結果に含まれる `metadata` から「ファイルパス」と「ページ番号」を取得します。
- **表示**: 同一ファイル内の複数ページが参照された場合は、まとめて表示します（例: `document.pdf (p.1, p.3)`）。
- **ファイルオープン**: Pythonの `os.startfile()` 関数を使用し、Windowsの関連付けられたアプリケーションでPDFを開きます。

## 使い方
1. アプリケーションを起動します。
   ```bash
   streamlit run app.py
   ```
2. ブラウザで `http://localhost:8501` にアクセスします。
3. サイドバーの設定:
   - **OpenAI API Key**: OpenAIのAPIキーを入力します（環境変数で設定済みの場合は不要）。
   - **PDFをアップロード**: 分析・質問したいPDFファイルを選択してアップロードします。
4. チャット開始:
   - 下の入力欄に質問を入力します。
   - 回答とともに、参照したPDF名とページ数が表示されます。
   - 「開く」ボタンを押すと、手元のPDFリーダーでそのファイルが開きます。

## 技術スタック
- **Frontend**: Streamlit
- **LLM/Embeddings**: OpenAI (GPT-4o-mini)
- **Framework**: LangChain
- **Vector Store**: FAISS
- **Environment**: Windows (Local execution)
